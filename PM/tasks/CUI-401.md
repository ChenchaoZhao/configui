### 3. Mapper design (`widgets.py`)

**Public API:**

```python
def map_config_to_widgets(data: dict[str, Any], *, regex_overrides: dict[str, str] | None = None) -> Vertical:
```

Returns a `Vertical` of labeled widget rows, ready to mount into any Textual screen.

**Type→Widget mapping:**

| Python type | Textual widget | Details |
|---|---|---|
| `bool` | `Switch` | Value set to bool |
| `int` | `Input(type="integer")` | Default regex: `r"^-?\d+$"` |
| `float` | `Input(type="number")` | Default regex: `r"^-?\d+(\.\d*)?([eE][+-]?\d+)?$"` |
| `str` | `Input(type="text")` | No default regex |
| `dict` | `Collapsible` | Title = key; children recursively mapped |
| `list` | `Collapsible` | Title = key + `[N]`; items recursively mapped |

**Display:** Scalar pairs → `Horizontal(Static(label), widget)`. Nested → `Collapsible` with auto sub-Collapsibles for deeper nesting.

**Layout bug (fixed):** `Horizontal` with `width: auto` (default) on both children causes the `Static` label to consume all available space (`flex-grow: 1`), pushing the `Input` to `x=40` (off-screen). Fix: `Static` gets `width: auto + height: auto` (natural content size), `Input`/`Switch` gets `width: 1fr` (remaining space). CSS classes `scalar-label` / `scalar-input` enforce this.

**Regex overrides:** Lookup by dotted path (e.g., `"optimizer.lr"`).

**Widget IDs:** dotted path convention for future lookup.

**Reverse mapping:** (widget → config data) `collector.py` at `src/configui/tui/collector.py`
