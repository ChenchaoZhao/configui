### Layout

```
┌─ Header (filename, dirty *, [READ ONLY]) ───────────┐
│ ┌── Tree (30%) ────┐ ┌── Content (70%) ───────────┐ │
│ │ config            │ │  + model ─┐                 │ │
│ │ ├── model         │ │  ├─ architecture: resnet50  │ │
│ │ ├── training      │ │  ├─ pretrained: [Switch]    │ │

│ │ └── dataset       │ │                             │ │
│ └───────────────────┘ └─────────────────────────────┘ │
├── Footer: Ctrl+S Save · Ctrl+Shift+S Save As · Ctrl+Q ┤
└────────────────────────────────────────────────────────┘
```

### Sub-task 1: Header/Footer + Keybindings (`app.py`)

- `ConfigUIApp(App[None])` with Textual's `Header`/`Footer`
- **Header**: shows filename, `*` when dirty, `[READ ONLY]` in read-only
- **BINDINGS**:
  - `Ctrl+S` → `action_save` — collect via `map_widgets_to_config`, persist via `config.update()` + `config.save()`
  - `Ctrl+Q` → `action_quit` — if dirty, push confirmation modal; else exit
  - `Ctrl+Shift+S` → `action_save_as` — push `SaveAsScreen`
- **Dirty state**: `on_input_changed` / `on_switch_changed` set `self._dirty = True` → `watch_dirty` updates header subtitle and Footer save binding
- **Read-only mode**: Save/SaveAs actions are no-ops; Footer shows bindings greyed

### Sub-task 2: Tree/Sidebar (`app.py`)

- Left dock: `Tree` widget populated recursively from config keys in `on_mount`
- Right: `Vertical(id="main-content")` containing output of `map_config_to_widgets()`
- **Tree click → content sync** (`on_tree_node_selected`):
  - Find matching widget by dotted path ID
  - If `Collapsible` and collapsed → expand it
  - `widget.scroll_visible()`
  - Expand Tree ancestors
- **Content collapse → tree sync**:
  - `on_collapsible_expanded` / `on_collapsible_collapsed` → update corresponding `TreeNode`

### Sub-task 3: Save As Modal (`screens.py`)

- `SaveAsScreen(Screen)` modal:
  - `DirectoryTree("/")` — browse directories
  - `Input(id="save-filename")` — type file name
  - "Browse" button — focus `DirectoryTree`, optionally reveal typed path
  - "Save" button — call `config.save_as(Path(dir) / filename)`, pop screen, reset dirty
  - "Cancel" button — pop screen
  - Preview line showing full path

### CLI (`cli.py` + `__main__.py`)

```python
@click.command()
@click.argument("path", type=click.Path(exists=True))
@click.option("-r", "--read-only", is_flag=True, help="Open in read-only mode")
def main(path: str, read_only: bool) -> None:
    app = ConfigUIApp(path, read_only=read_only)
    app.run()
```

`__main__.py` delegates to `cli.main()`. `pyproject.toml` gets `[project.scripts]`.

## Bug Log

### CUI-402-B1: `test_save_as_dotdot_navigates_to_parent` flaky across platforms

**Symptoms:** Test passes on macOS but fails on Linux CI (`assert PosixPath('/bin') == PosixPath('/')`).

**Root Cause:** The test navigates ".." twice via `down` + `enter`. The second navigation fails because at root `/`, `NavigableDirectoryTree._populate_node` skips adding ".." (root's parent is itself). On Linux ("ubuntu-latest"), the first child is `bin` alphabetically, so "down" selects it instead of "..". On macOS, the temp file lives under `/var/folders/...` (symlink to `/private/var/folders/...`), so after the first ".." nav the tree lands at a non-root directory where a second ".." still exists.

**Fix:** Remove the redundant second navigation — one level sufficiently validates that ".." navigates to parent.
