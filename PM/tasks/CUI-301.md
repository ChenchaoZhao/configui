# Task: CUI-301 - YAML Strategy with ruamel.yaml

**Milestone:** Advanced Serialization (YAML/TOML)

## Description

Implement YAML support with a focus on comment preservation.

## Design Decisions

- **Anchors/Aliases:** Preserve as references — `typ='rt'` keeps anchor/alias structure intact.
- **YAML Tags (e.g. `!!float`):** Convert to native Python types (default RT behavior).
- **Key ordering:** Preserve original ordering from file (default RT behavior).

### 5. Refactor: Extract Shared Atomic Write

`JsonConfig.save_as` and `YamlConfig.save_as` share identical atomic-write logic (tempfile + os.replace + finally cleanup). The serialization itself differs (json.dump vs yaml.dump). Refactor into a shared utility:

Create `src/configui/config/_atomic.py`:

```python
def atomic_write(path: Path, writer: Callable[[IO[str]], None]) -> None:
    path = Path(path)
    fd, tmp_path = tempfile.mkstemp(suffix=".tmp", dir=path.parent)
    try:
        with os.fdopen(fd, "w") as f:
            writer(f)
        os.replace(tmp_path, path)
    except BaseException as e:
        msg = f"Failed to save config to '{path}'"
        raise RuntimeError(msg) from e
    finally:
        with suppress(BaseException):
            os.unlink(tmp_path)
```

Both `save` and `save_as` use `atomic_write`, since direct-to-path writing shares the same vulnerability (partial write on crash):

```python
# JsonConfig
def save(self, **kwargs: Any) -> None:
    atomic_write(self._path, lambda f: json.dump(self._data, f, indent=2, ensure_ascii=False, **kwargs))

def save_as(self, new_path: Path, **kwargs: Any) -> None:
    atomic_write(new_path, lambda f: json.dump(self._data, f, indent=2, ensure_ascii=False, **kwargs))

# YamlConfig
def save(self, **_kwargs: Any) -> None:
    atomic_write(self._path, lambda f: self._yaml.dump(self._data, f))

def save_as(self, new_path: Path, **_kwargs: Any) -> None:
    atomic_write(new_path, lambda f: self._yaml.dump(self._data, f))
```

This eliminates the `BaseException`/`suppress`/`os.unlink` duplication in both classes.
