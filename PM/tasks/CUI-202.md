# Task: CUI-202 - JSON Implementation

**Milestone:** Core Logic & JSON Strategy

## Description

Implement the first concrete strategy using the Python `json` standard library.

## Plan

### New File: `src/configui/config/json_config.py`

- **`JsonConfig`** — concrete implementation of the `Config` protocol
- Constructor: `__init__(self, path: str | Path)` — stores the path, initializes `_data` as `None`
- `load()` — reads file → `json.loads()` → stores data; wraps `JSONDecodeError` in a descriptive `ValueError`
- `save()` — writes `_data` to `_path` with `json.dumps(indent=2, ensure_ascii=False)`
- `save_as(new_path)` — writes `_data` to `new_path` without changing `self._path` (atomic write, original path unchanged)

### Modified: `src/configui/config/__init__.py`

- Add `JsonConfig` to the public exports

### New File: `tests/config/test_json_config.py`

Tests using `tmp_path` for file isolation:

| Test | Description |
|---|---|
| `test_load_reads_valid_json_object` | Load a simple `{"key": "value"}` |
| `test_load_reads_json_with_all_types` | null, bool, int, float, str, list, dict |
| `test_load_reads_json_array` | Top-level array |
| `test_load_reads_nested_structure` | Deeply nested dict |
| `test_load_with_malformed_json_raises_value_error` | Syntax error → ValueError |
| `test_load_with_empty_file_raises_value_error` | Empty file → ValueError |
| `test_load_with_nonexistent_file_raises_file_not_found` | Missing file → FileNotFoundError |
| `test_save_writes_correct_content` | Load then save, verify file contents |
| `test_save_with_unicode_preserves_chars` | Unicode round-trip |
| `test_save_as_writes_to_new_path` | save_as writes to new file, original path unchanged |
| `test_round_trip_preserves_data` | Load → save → load, verify data equality |
